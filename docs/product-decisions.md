# DBKang Toolbox V1 权威产品决策

本文件依据“阿康工具箱脑暴”完整对话整理。发生冲突时采用更靠后的用户决定。

## 产品边界

- V1：成就、Lo-fi 自习室（内含音乐、环境音、番茄钟、统计、在线人数）、个人资料、课程公告、管理员后台、Userscript、阿康浏览器与更新体系。
- V2：聊天室、漂流瓶及其他社交能力。V1 不展示占位入口。
- Desktop Only，仅支持浅色模式；视觉应白色、清爽、接近学习通原生，不使用 emoji 作为正式 UI 图标。
- 工具箱主体为服务器托管的 iframe Web App；Userscript 保持薄，只负责学习通解析、入口注入、作业扫描和 postMessage 桥接。
- 学生默认进入成就页。音乐不是一级页面，音乐库、播放器、环境音、番茄钟、专注统计与在线人数全部属于 Lo-fi 自习室内部。

## 数据作用域

- 用户全局：学号、真实姓名、昵称、头像、累计专注、番茄统计、番茄设置、音乐/环境音偏好。
- 课程级：成员关系、公告、成就定义、成就解锁、班级解锁率、作业成绩。
- 全课程共用：音乐库、Lo-fi MP4、雨声/风声/篝火等资源。
- 学号全局唯一；格式固定为 `YYYY + 3 位内部编码 + 1 位班级 + 2 位序号`。

## 身份与课程

- 学生身份来自学习通当前页面，服务端采用轻信任模型，明确允许高级用户伪造；不可用于成绩修改、考试等高可信业务。
- 课程以学习通 `courseId` 为唯一键，教学班以 `clazzid`（API `classId`）为唯一键；课程名和班级名均不得参与归属匹配。后台课程名称仅为管理员备注，学生显示自己在学习通页面看到的名称。
- 同一学号多设备同时在线；在线人数与重叠专注时间按学号去重。
- 学生第一次进入已启用课程时自动建立课程成员关系，无需管理员预导入。
- Userscript 不写死课程白名单，向服务器实时查询。课程结课时入口不显示且后端禁止访问；管理员仍可管理历史数据。
- 作业成绩只在学生真正打开工具箱后扫描，不在普通学习通页面后台扫描。
- 默认昵称为学习通真实姓名；默认头像为正式图片资产。学生可设置 1～20 字符昵称并上传头像，头像统一中心裁切、压缩为 512×512；管理员可编辑或重置资料。

## Lo-fi 自习室

- 一个必须成功播放、静音循环且不可关闭的 MP4 背景；失败时提示“背景加载失败，请稍后重试”。
- 环境音首批为雨声、风声、篝火，循环 MP3，可与音乐叠加，分别调节音量；单个资源失败只禁用对应按钮。
- 番茄钟默认 25/5，可配置专注 1–180 分钟、休息 1–60 分钟、1–20 轮；配置保存在服务器。
- 专注/休息自动衔接；最后一轮专注完成后结束；允许无限暂停；刷新、关闭或崩溃后不恢复当前进度。
- 只累计专注阶段；中途停止仍累计已完成时间，但不增加完成番茄数。精确到秒，展示可按分钟。
- 10 秒 HTTP 心跳，不依赖 WebSocket。断网时本地计时继续，但断网区间不计入服务端统计；恢复后自动重新计入。
- 多设备专注区间取并集；不同番茄各自完整完成则分别计数，同一 `sessionId` 的重复请求必须幂等。

## 音乐

- 服务器目录即歌单，启动时扫描一次；曲目按文件名排序；解析 MP3 Tag 的标题、歌手、专辑、时长和封面。
- 元数据只驻留内存；封面允许写临时缓存目录；无封面使用实际默认图片资产。
- 支持 HTTP Range、进度拖动、顺序/列表循环/随机/单曲循环；默认列表循环。
- 记住播放模式、音乐音量与上次歌单；不记住当前歌曲与进度，也不自动播放。
- V1 无搜索、歌词；音乐行为不参与成就。

## 成就

- 成就按课程隔离，专注与番茄累计数据为用户全局数据；规则可引用这份全局状态。
- 规则仅在服务端通过受限表达式解释器执行，支持 `state.*`、`event.*`、事件累计计数和 `homework("assignmentId")`。
- 支持自动/手动、隐藏、进度、金/银/铜、管理员自定义顺序；展示时已解锁优先，组内按管理员顺序。
- 满足条件即永久解锁；规则改严不撤销；只有管理员可手动撤销。
- 创建/修改自动成就后立即对课程现有学生补判定。
- 硬删除成就，同时删除所有解锁记录，效果如从未存在。
- 解锁率范围为当前 `courseId + classId`；分母为至少打开过一次工具箱的该教学班课程成员；手动授予也计入。
- 事件只保存累计计数，不保留通用完整事件历史；必要业务明细（专注区间、作业快照）仍持久化。
- 作业快照持久化；当前不可见的作业历史保留但不可用于新的成就判定。

## 管理、部署与发布

- 一个独立管理员账号 + 密码；支持 Dashboard、课程、学生、成就、公告管理及批量授予/撤销。
- 公告按课程隔离，可多条切换，仅纯文本，无全局公告。
- 学生列表支持课程、年级、班级和学号/姓名/昵称筛选；管理员可禁用学生并填写学生端可见原因、手动恢复、编辑或重置资料。
- 成就支持编辑、硬删除、指定学号/班级/全课程批量授予与撤销，以及跨课程复制配置（不复制解锁记录）。公告支持创建、编辑、删除和排序。
- 后端：Python、FastAPI、SQLite WAL、uv、Alembic，目标最多 50 人；不引入微服务、Redis、消息队列或 WebSocket 集群。
- 前端：Vue 3、TypeScript、Vite、Reka UI、UnoCSS；pnpm Monorepo。
- Docker Compose 部署到内网服务器，经单一 Cloudflare Tunnel 域名提供所有 API 与资源。Cloudflare 等外围运维不属于核心代码范围。
- 产品只暴露一个服务入口。根路径为客户端下载页；`/toolbox/`、`/admin/`、`/api/v1/`、`/assets/`、`/updates/` 均为同一协议、域名和端口下的路径。Vite 的 5173/5174 只允许作为 HMR 内部开发端口。
- 推送 `vX.X.X` Tag 由 GitHub Actions 发布 GitHub Release 与 GHCR；生产服务器由管理员手动更新；数据库容器启动时自动迁移，失败阻止服务启动。
- V1 不自动备份，不做生产自动 CD。

## 阿康浏览器与更新

- 阿康浏览器和高级用户安装的 `.user.js` 使用同一份 Userscript；浏览器只是提前装好兼容的脚本管理器，不维护第二套工具箱逻辑。
- 浏览器为 Windows 10/11 x64 的普通 Chromium 界面；保留地址栏、标签页、版本页和原 Chromium 图标，不支持 ARM64。启动始终打开学习通首页，不恢复旧标签页；所有窗口关闭后退出后台进程。
- 真便携目录，不写注册表、系统目录、`AppData` 或桌面快捷方式；Cookie 与 `user-data/` 永久保留在便携目录。单实例，再次启动时交给已有进程打开。
- 首次分发为单个自解压 EXE，在 EXE 所在位置建立 `DBKangBrowser/`；同一 EXE 也支持保留用户数据的离线升级，不允许降级。
- 只设 Stable 通道，测试版手动拷贝。仅启动时检查更新；失败则跳过并继续启动。发现更新时提供“立即更新 / 下次启动提醒”。
- 文件级差分优先、完整包兜底，使用 SHA-256，不做数字签名；更新失败自动回滚并将坏版本加入本地黑名单。更新永不覆盖 `user-data/`。
- Chromium 使用可信预编译版本，具体版本在构建配置中固定；不自编译 Chromium，不自动升级内核版本。
